# Full-Page Animation Concepts

These are exploratory visual directions for the portfolio. None of them should be added all at once. The best result will come from testing one full-page system at a time and keeping the final site calm enough for recruiters and technical reviewers to read.

## Evaluation Criteria

- The animation must support the story: applied AI, robotics, control, simulation, embedded systems.
- It must not hide text, lower contrast, or make the page feel like a gaming splash screen.
- It should work as a first-viewport identity layer or a subtle whole-page atmosphere.
- It must respect `prefers-reduced-motion`.
- It should remain lightweight enough for GitHub Pages and mobile devices.

## Concepts

1. `01-translucent-systems-console.md`
   A glassy technical console layer with faint terminal logs, simulation metrics, and moving grid traces.

2. `02-diffusion-field-overlay.md`
   A soft diffusion/noise field that behaves like simulated uncertainty resolving into structure.

3. `03-robotics-trajectory-map.md`
   A full-page motion-trace system inspired by robot end-effector paths, rollouts, and control trajectories.

4. `04-research-paper-reveal.md`
   A document-layer animation where paper figures, metrics, and evidence reveal like a technical dossier.

5. `05-embedded-signal-scan.md`
   A biomedical/embedded signal motif using waveform scanning, spectrogram lines, and dose-step pulses.

## Short Recommendation

For this portfolio, the safest premium direction is `03-robotics-trajectory-map.md` with a very restrained version of `04-research-paper-reveal.md`.

The most visually distinctive direction is `02-diffusion-field-overlay.md`, but it needs careful restraint because it can become abstract and less resume-like.

The most "hacker" direction is `01-translucent-systems-console.md`, but it should be used sparingly so the site does not look like a fake cybersecurity template.
